绩效评价与归因

用一组假设的股票/债券组合，把 8.7% 的组合收益与 6.8% 的基准收益比较，扣除 0.60% 费用后分解配置、选择与交互效应，并说明一年样本为何不足以证明能力。

问题与输出

绩效评价回答“结果是否达到目标、是否承担了相应风险”；归因回答“超额收益来自配置、选择还是交互”。输出是净收益、相对基准的超额收益、风险调整指标、归因分解和不确定性说明，不是对管理人的总体评判。

输入与数据要求

需要组合与基准的同期收益、期初权重、费用、现金流和样本长度。收益频率应一致，权重应为同一时点，基准须可投资且风格匹配。示例为假设的一年期、12 个月观测：组合股票/债券 70/30，基准 60/40；股票组合收益 12%、基准 10%；债券组合 1%、基准 2%；年费 0.60%；跟踪误差 4%。

业绩呈现的口径按 CFA Institute 的 GIPS：以时间加权总收益报告组合业绩、按 composite 汇总并作出必要披露，目标是公平呈现与充分披露[1]。

假设

收益为毛收益，费用按年 0.60% 近似直接从超额收益中扣减；无期间现金流，或已用时间加权收益消除现金流影响；单币种、无税；权重在期初确定；显著性检验假设月度超额独立同分布；所有数字为教学假设。

步骤

  1. 组合收益 0.7×12% + 0.3×1% = 8.7%；基准 0.6×10% + 0.4×2% = 6.8%；毛超额 1.9 个百分点。
  2. 扣费：净超额约 1.9%-0.60% = 1.30 个百分点。
  3. 配置效应 Σ(w_p-w_b)×r_b = 0.1×10% + (-0.1)×2% = 0.8 个百分点。
  4. 选择效应 Σw_b×(r_p-r_b) = 0.6×2% + 0.4×(-1%) = 0.8 个百分点。
  5. 交互效应 Σ(w_p-w_b)×(r_p-r_b) = 0.1×2% + (-0.1)×(-1%) = 0.3 个百分点；三项合计 1.9，与毛超额一致。
  6. 风险调整：信息比率 1.30%/4% = 0.33。
  7. 显著性：月均超额 1.30%/12 = 0.108%，月跟踪误差 4%/√12 = 1.15%，两者之比 0.108%/1.15% ≈ 0.09 是月均信息比，再乘 √12 得 t ≈ 0.33，不能拒绝“无技能”。

组合层面的算法按 OpenStax：组合收益是各资产收益的加权平均，组合波动率取决于权重、各资产波动率与相关性[2]。

结果解读

1.30 个百分点的净超额在一年内与噪声难以区分；0.8 个百分点的配置效应来自超配高收益股票，0.8 个百分点的选择效应来自股票超基准 2 个百分点、债券落后 1 个百分点的净结果，0.3 个百分点来自两者交互。归因是事后分解，不是可重复的能力证明；样本越短、跟踪误差越大，结论越弱。同一组数字换用不同归因口径，会得到不同的配置与选择拆分，因此口径必须事前固定并披露。评价应同时看净收益、风险、风格一致性和规则遵守，而不是只看排名。

失败条件

  • 基准与组合的风格、币种或期限不匹配；
  • 用毛收益评价净结果，忽略费用、税费和滑点；
  • 样本过短或经过筛选，存在幸存者偏差；
  • 期间权重已变化却仍用期初权重归因；
  • 跟踪误差为零或分母为零；
  • 隐藏归因残差，或把交互项随意并入某一项；
  • 用单年结果推断长期能力。

验证

用日频或周频数据重算；换用风格相近的替代基准；检查三项效应加总是否等于超额收益；用滚动窗口和自助法估计区间；比较扣费、扣税后的结果；核对组合与基准的现金流处理。

复现

R_p=Σw_p r_p；R_b=Σw_b r_b；配置=Σ(w_p-w_b)r_b；选择=Σw_b(r_p-r_b)；交互=Σ(w_p-w_b)(r_p-r_b)。示例：8.7%-6.8%=1.9%；1.9%-0.60%=1.30%；0.8+0.8+0.3=1.9。

知识点精读

基准

定义：基准是评价投资组合表现的参照，应匹配投资范围、风险、币种和约束。

机制：基准可以是市场指数、同业组、负债或绝对目标；选择影响归因、激励和资金流。

例子：例如中国股票基金以沪深 300 为基准，全球组合用本币或对冲后的全球指数。

边界：基准不是随意挑低标尺；不匹配会掩盖风险、制造虚假超额收益，基准也可能被操纵或过时。

资金时间加权收益

定义：时间加权收益剔除现金流时点影响、衡量策略本身，资金加权收益反映投资者实际资金经历。

机制：时间加权适合比较管理人，资金加权受投入和赎回时点影响；大额现金流会显著改变资金加权结果。

例子：例如基金年化 10%，但投资者在高点买入、低点赎回，资金加权收益可能为负。

边界：两种收益不是一回事；只看时间加权会忽略投资者择时，只看资金加权会把投资决策和管理能力混在一起。

风险调整

定义：风险调整收益把回报与波动、下行、beta 或最大回撤比较，常用夏普、索提诺、信息比率和 Treynor。

机制：指标应匹配风险定义和策略；夏普用总波动，索提诺用下行，信息比率用跟踪误差。

例子：例如两只基金收益相同，波动更低者夏普更高，风险调整后更优。

边界：风险调整不是单一排名；指标依赖样本、频率和尾部，杠杆可提高夏普但增加爆仓风险，高收益也可能来自未计入风险。

风格与贡献

定义：风格是组合的价值、成长、规模等特征，业绩归因把收益分解为市场、行业、选股、因子和交互效应。

机制：归因区分 beta 与 alpha、配置与选择；风格暴露和行业权重决定组合在不同环境的表现。

例子：例如组合跑赢基准 3%，归因显示 2% 来自行业超配、1% 来自选股。

边界：归因不是精确解释；模型、交叉项和残差会影响，风格暴露可能隐藏，短期业绩也可能由风格 beta 而非技能驱动。

运气技能

定义：运气是随机或不可重复的结果，技能是可重复的判断、执行和风险管理能力。

机制：区分两者需长样本、基准、过程和样本外验证；短期高收益可能来自 beta、风格或运气。

例子：例如经理连续两年跑赢，但持仓与热门因子高度重合，可能不是选股技能。

边界：业绩不是技能证明；幸存者偏差、回测和短期样本会夸大，运气也会让人过度自信，过程比单次结果更重要。

数据与制度核对：绩效评价

把“绩效评价”放进真实数据之前，先核对四件事。第一是统计单位：来源报的是水平值、增长率、指数还是占比，分母是总产值、人口、劳动力还是金融资产；同一句话换掉分母就会得到不同结论。第二是时间口径：名义值与实际值、季调与非季调、财年与日历年不能直接拼接，涉及“基准”时尤其要写明基期和折算方法。

第三是制度边界。归因分析在来源国的法律、监管和会计规则下成立，换到另一套制度里，定义可能不覆盖同一批主体；跨境比较要先检查样本是否被同一规则约束。第四是反向核对：用另一个独立来源重算关键比例，至少让数量级、方向和单位对得上，再讨论因果。

这四步不能保证结论正确，但能挡住最常见的错误：把不同口径的两个数字相除、把短期波动当成长期趋势、把制度差异误写成行为差异。文章中的教学数字均为假设，正式引用时以来源原文的日期、单位和脚注为准。

边界条件与迁移练习：绩效评价

学习“绩效评价”最容易停在定义。真正要练的是把它和“基准”分开：前者回答哪个变量在动，后者回答这个变量通过什么渠道影响结果。两者经常同时出现，但一个描述状态，一个描述传导；把传导写成状态，就会把相关性误当因果。与“归因分析”的区别则在于层次：前者可以在单个主体上观察，后者要求一组共同规则约束同一批主体。三层混在一起，文章就会看起来什么都说了，实际什么都不能检验。

边界条件要写成可观察的门槛，而不是形容词。第一，样本门槛：数据是否覆盖完整周期，是否包含压力期，是否排除了退出市场的失败者。第二，单位门槛：水平值、增长率、比率和指数不能互换，分母必须明示。第三，制度门槛：规则生效日、适用主体和豁免条款是否一致。第四，行为门槛：当指标改变时，主体是否真的会调整决策，还是只是账面数字变化。四条中任何一条不成立，结论就只能作为情景，不能作为基准。

迁移练习的做法是换三个维度各问一次。换主体：从企业换到家庭，从银行换到基金，绩效评价的分子分母是否仍然成立？换时间：从季度换到年度，从正常期换到危机期，参数是否稳定？换制度：从一套监管换到另一套，基准的激励是否方向相反？三次换完，仍能复述同一条机制，才算掌握；一换就崩，说明原来记住的是案例，不是概念。

最后做一次自测：用 100 字解释“绩效评价”，必须包含一个单位、一个时间口径和一个反例；再用 100 字说明“基准”在什么条件下会失效。两段都写不出，就回到模块母文和同模块的另一篇主文，先把定义与口径对齐。模块深度不是字数，而是能否在换主体、换时间、换制度后仍给出可复核的判断。

复核题：绩效评价

  1. 用一句话说明“绩效评价”的分子、分母和单位，再说明它与“基准”不是同一个指标。
  2. 给出一个“归因分析”改变后结论翻转的例子，标明改变了哪条规则。
  3. 找一组跨期数据，说明季调、基期或修订如何改变方向。
  4. 设计一个换主体后的检验：从企业换到家庭，或从银行换到基金，哪些参数必须重估？
  5. 写一条可证伪判断：如果哪一个可观察信号出现，就应放弃本文结论？

五题不要求长答，但每题必须留下数字、日期或来源位置。答不出来，说明模块还停留在名词层；能答出来，才具备把概念迁移到新数据上的最低条件。

判断表：基准、资金时间加权收益、风险调整

把这三个知识点放进同一个判断，顺序是“对象—机制—边界”：先确认看的是什么，再确认因果链是否成立，最后确认结论能否外推。如果第一步的定义和第二步的指标不是同一口径，后面的计算只是在错误对象上求精确；如果第三步没有写清边界，单一样本的成功会被误当成普遍规律。

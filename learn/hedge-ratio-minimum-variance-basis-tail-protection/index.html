对冲比率：方差最小、基差与尾部保护的取舍

对冲比率不是“100% 就对”，而是“要对冲多少、用什么工具、承担多少基差风险”。方差最小比率降低波动，但可能牺牲收益；尾部保护需要非线性工具，而不是简单加空头。

定义与直觉

**对冲比率（h，hedge ratio）**是衍生品头寸与被对冲资产的比例。最小方差对冲比率 h* = Cov(资产, 对冲工具) / Var(对冲工具)，让组合方差最小。

若资产与工具完全同向、同幅变动，h*=1；若工具波动更大，h*<1；若两者负相关，h* 可能为负（反向对冲）。

基差风险是被对冲资产与工具价格差异变化的风险：期货与现货、不同交割地、不同信用等级都会产生基差。尾部风险是极端事件下线性对冲失效的风险；期权、尾部基金和动态对冲更适合尾部[1][2]。

正式表达与示例

假设资产月度波动 8%，对冲工具波动 10%，相关系数 0.8。h* = 0.8×8%/10% = 0.64，即对冲 64% 的暴露。

若完全对冲 100%，组合仍有基差风险：工具涨 10%、资产涨 8%，空头亏损 10%、资产盈利 8%，净亏 2%。若只对冲 64%，净结果更接近零，但仍有基差。

若市场跳空，线性空头无法保护上行尾部；买入看跌期权可以限制下行，但权利金是成本。对冲比率要按目标选择：降波动用 h*，保尾部用期权或尾部策略。以上数字均为教学假设。

三个取舍

取舍一：方差 vs 收益。 最小方差比率降低波动，也可能降低预期收益；若资产有正 alpha，过度对冲会削掉收益。

取舍二：线性 vs 非线性。 期货、远期和掉期是线性工具，成本低但尾部保护有限；期权是非线性，保护尾部但付费。

取舍三：静态 vs 动态。 静态比率按估计设定，动态比率随相关性调整；动态对冲交易频繁，模型风险更高。

对冲不是消除风险，而是把风险换成另一种风险：基差、对手方、流动性和模型风险。选择工具前要明确要对冲什么[3][4]。

适用条件、边界与常见误区

边界一：相关性不稳定。 危机时资产与工具的相关性会变，历史 h* 可能失效；要 stress test。

边界二：工具流动性。 期权和尾部工具在压力下可能流动性枯竭，权利金和买卖价差扩大。

边界三：会计与保证金。 对冲工具的保证金、抵押品和会计处理会影响现金流；不能只看经济对冲效果。

误解一：100% 对冲最安全。 完全对冲仍有基差和工具风险；过度对冲可能降低收益。

误解二：对冲就是买保险。 线性对冲降低波动但不保尾部；保险需要期权或非线性工具。

深化：最优对冲比率、基差与尾部保护

对冲比率不是“1:1”。最小方差对冲比率等于现货与期货收益的协方差除以期货收益的方差：h*=Cov(ΔS,ΔF)/Var(ΔF)。若两者完全同向，h*=1；若期货波动更大，h小于 1；若相关性低，h接近 0。用 1:1 对冲，可能对冲不足或过度。

基差风险是对冲的剩余风险。基差 = 现货价格 − 期货价格；基差变化会带来盈亏，即使价格方向判断正确。基差受仓储、运输、利率、便利收益和合约到期影响；不同交割地、品质和时间的基差不同。

动态对冲要处理路径依赖。期货需要保证金，价格不利时追加保证金；若资金不足，可能在最差时点被迫平仓。对冲比率、保证金和流动性要一起规划，不能只算理论方差。

尾部保护与最小方差目标冲突。最小方差对冲降低日常波动，但可能在对冲尾部时过度；期权对冲保留上行、支付权利金，适合尾部保护但成本高。选择取决于目标：降低波动还是保底。

交叉对冲用相关但不同的资产对冲，基差风险更大；相关性在压力时可能失效，历史相关性不能直接外推。

评估：对冲后波动、最大回撤、基差盈亏、保证金占用、展期成本。只看“对冲后收益”会忽略风险和成本。

常见误用：把对冲当成消除风险、用历史相关性代替实时基差、忽略保证金和展期、过度对冲导致方向暴露反转。

最后，对冲是“用确定的成本换不确定的损失”，不是免费保险；比率、工具和期限要匹配风险来源。

对冲复核清单

复核一个对冲方案，先确认它降低的是目标风险，而不是把风险换成另一种风险：

  1. 对冲目标是什么？ 降低波动、锁定价格、保护尾部还是提高夏普；目标不同，工具和比率不同。
  2. 最小方差比率是否估计稳定？ Cov/Var 用历史窗口估计，基差和相关性变化会让 h* 漂移；要报告估计误差。
  3. 基差风险有多大？ 期货与现货、交割地、信用等级和期限不匹配都会产生基差；压力期基差会跳变。
  4. 尾部保护是否线性？ 期货空头在极端上涨中失效；期权、动态对冲和尾部基金的成本不同。
  5. 对冲成本是否被计入？ 保证金、展期、期权费和流动性折扣会侵蚀收益；只算价格风险会高估效果。
  6. 流动性和追加保证金能否承受？ 极端行情中保证金上升，可能被迫平仓；要对资金链做压力测试。
  7. 对冲比率是否随观点调整？ 战术观点可以偏离 h*，但要写明偏离理由和回撤阈值。
  8. 会计和税务处理是否一致？ 对冲工具的分类、损益确认和跨期匹配会影响报告结果。

好的对冲不是“有没有买保险”，而是“保险覆盖了哪种风险、成本多少、极端时是否还有效”。

最后，对冲方案要写明“什么情况下停止或调整”：基差超过阈值、相关性反转、保证金不足或对冲目标变化。没有退出规则的套保，容易在压力期变成新的风险源。

最小行动： 为每个对冲写一张一页纸，列目标风险、工具、比率、基差阈值、保证金上限和退出条件；压力测试覆盖三倍历史波动。

记录： 基差和保证金数据按日留档，事后才能判断对冲失效发生在哪一层。

一句话： 对冲的退出规则和入场规则同样重要。

备注： 对冲比率和基差要一起留档，单看损益无法复盘。

标注： 压力测试每季更新，并覆盖保证金翻倍情形。

反证条件

对冲比率的结论依赖基差和相关性稳定：

  1. 基差非平稳。 若现货与期货的基差结构变化，历史 h* 会漂移，静态比率失效。
  2. 期权波动率错价。 若隐含波动率低于真实尾部风险，保险成本被低估。
  3. 保证金顺周期。 若压力期保证金上升，对冲者可能被迫平仓，反而放大风险。
  4. 相关性 regime 切换。 若危机中资产与工具相关性反转，线性对冲失效。

实践含义： 对冲方案要写清目标风险、比率、基差阈值、保证金上限和退出条件；没有退出规则的套保，会在压力期变成新的风险源。

数据附注： 用总回报和全成本比较对冲效果；只算价格损益，会漏掉保证金、展期和期权费。

范围说明： 用同一会计和税务口径比较对冲；不同工具的分类会影响损益确认和跨期匹配。

最后： 会计和税务口径会改变对冲损益的确认；比较策略时要用同一 basis，否则 Sharpe 不可比。

核对： 比较对冲前，把损益放到同一会计和税务基础上。

练习

  1. 写出最小方差对冲比率公式。

  2. 资产波动 8%、工具 10%、相关 0.8，h* 多少？

  3. 100% 对冲、工具涨 10%、资产涨 8%，净结果多少？

  4. 基差风险来自哪些差异？

  5. 线性与非线性对冲各适合什么目标？

  6. 动态对冲的模型风险是什么？

  7. 判断：100% 对冲最安全吗？说明理由。

  8. 最小方差对冲比率如何计算？为什么它通常不是 1？

  9. 基差风险为什么会让“方向判断正确”仍然亏钱？

练习参考答案

  1. h* = Cov(ΔS,ΔF) / Var(ΔF)。
  2. h* = 0.8×8%/10% = 0.64（用相关系数×波动率比）。
  3. 工具涨 10%、资产涨 8%，100% 对冲净结果约 −2%（未计基差和成本）。
  4. 交割地、品质、时间、仓储、运输、利率和便利收益；期货与现货的差异都会变。
  5. 线性对冲适合降低日常波动；期权等非线性工具适合尾部保护和保留上行。
  6. 模型假设波动和相关稳定，实际会变；动态对冲的路径、保证金和流动性也会带来风险。
  7. 不是。100% 对冲可能过度，忽略基差、保证金和展期成本；最优比率通常小于 1。
  8. 用协方差除以期货方差；期货波动更大或相关性低时，h* 小于 1。
  9. 因为基差变化会带来盈亏，即使价格方向判断正确；基差受供需、仓储和合约到期影响。

本章要点

  • 最小方差对冲比率由协方差除以期货方差决定，通常小于 1。
  • 基差风险来自交割地、品质、时间和供需，方向正确也可能亏。
  • 动态对冲要预留保证金和流动性，避免在最差时点被迫平仓。
  • 最小方差与尾部保护目标不同，期权对冲成本更高但保留上行。
  • 评估要看对冲后波动、回撤、基差和展期成本，而不只是收益。

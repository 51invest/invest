收益风险与成本的取舍

把净名义收益、风险与费用放到同一口径比较，用情景区间而非单一预期值判断取舍；示例数字均为假设。

问题与输出

投资广告常只给一个收益率，但结果取决于承担了多少风险、付出了多少成本、通胀侵蚀了多少购买力。本文要解决的问题是：在若干可选方案中，如何用同一口径比较净收益、风险与成本。输出是一张对比表和一组情景，而不是“最佳产品”的结论。

输入与数据要求

  • 名义收益率及其时间单位；
  • 通胀率或价格指数；
  • 费用：管理费、交易佣金、买卖价差、托管费等；
  • 税费及纳税时点；
  • 风险：情景区间、历史波动、最大回撤；
  • 流动性、期限和最低持有要求；
  • 数据来源、样本区间和费用口径。

所有输入必须同币种、同期限、同税制。历史收益不能直接当作未来预期。

假设

示例假设：持有 1 年；期初 100,000 元；通胀 2.5%；每年费用 1.0 个百分点，直接从名义收益率中扣除；不考虑税费；收益率只是情景，不是预测。以上数字均为教学假设，不是任何产品的实际业绩。现实中的费用可能按期末资产或平均资产收取，必须按产品文件核对：若 1.0% 的费用按期末资产收取，100,000 × 1.07 × (1 - 1%) = 105,930 元，净名义收益是 5.93% 而不是扣百分点得到的 6.0%。

步骤

  1. 写下毛名义收益率，并标明时间单位。
  2. 扣除费用和税费，得到净名义收益率。费用是成本，不是市场下跌。
  3. 换算实际收益：r_real = (1 + r_net) / (1 + π) - 1，其中 r_net 是净名义收益。低通胀时可用 r_real ≈ r_net - π，但要检查误差。换算式的推导与误差来源以实际收益与购买力主文（INV-003）为准，本文只取这条结论。
  4. 用至少三个情景描述风险：下跌、基准和上涨；同时记录最大回撤和流动性限制。
  5. 比较每单位风险能获得多少收益，而不是只比名义收益。口径固定为“同一持有期、同一收益定义下的均值除以标准差”，即 比值 = 均值 / 标准差；这是本文的自算比值，不减无风险利率，因此不是夏普比率。用来源 3 的表 12.4（1981–2020 年名义算术平均收益与其标准差）自算：美国大盘股 12.64 / 16.06 = 0.787，Baa 级债券 10.34 / 7.67 = 1.348，美国国库券 3.94 / 3.39 = 1.162[3]。三个比值都高于股票这一点本身就提醒：比值对分母（波动）极敏感，且该表是名义口径，不能与本文净实际收益直接同类比较；比较时两侧必须同为名义或同为实际、同为一年的持有期。
  6. 区分确定性：成本几乎确定会发生，收益不确定。

图表

图 2 把示例的收益拆成四步：毛收益先加上去，费用扣掉，通胀再扣掉，最后剩下的才是购买力。费用几乎确定，7.0% 的毛收益只是情景。

示例

假设方案 A 的毛名义年收益为 7.0%，费用 1.0 个百分点，净名义收益为 6.0%，期末 106,000 元。按 2.5% 通胀：

  • 精确实际收益：1.06 / 1.025 - 1 = 3.41%；
  • 近似值：6.0%-2.5% = 3.5%，高估约 0.09 个百分点；
  • 期末 106,000 元相当于今天的 106,000 / 1.025 = 103,414.63 元。

若市场下跌 10.0%，扣除费用后净名义收益为 -11.0%，期末 89,000 元；实际收益 0.89 / 1.025 - 1 = -13.17%，相当于今天 86,829.27 元。若上涨 20.0%，净名义收益 19.0%，实际收益 1.19 / 1.025 - 1 = 16.10%。作为对照，假设存款名义利率 3.2% 且无费用，实际收益为 1.032 / 1.025 - 1 = 0.68%。

方案 A 的基准情景实际收益高于存款，但一年结果可从 -13.17% 到 +16.10%；存款的 0.68% 更确定。这就是取舍：更高的预期收益通常来自承担更大的不确定性，而不是免费的午餐。

结果解读

名义收益说明钱变成了多少，实际收益说明购买力增加了多少。费用会压低回报 [1]；费用在好坏年份都收，收益却不确定，所以低成本在长期更值得关注。风险是收益的不确定性，标准差越大表示风险越高 [2]；它不只是“可能亏钱”，而是结果的范围、概率和流动性约束。标准差把上涨与下跌同样计入，也不反映亏损的路径和能否变现，所以本文用情景区间和最大回撤补充波动，而不单凭波动衡量风险。历史数据也提醒平均收益伴随波动：1981—2020 年美国大盘股（large-company stocks）名义年收益的算术平均约 12.64%，标准差约 16.06% [3]。预期值不能替代对下行情景的检查。 （口径补注：教材表 12.4 中该行的教材标签逐字为 Large company stocks（即美国大盘股，不是泛指一切股票），表头逐字为 Nominal Average Annual Returns 1981–2020 Standard Deviation of Returns 1981–2020，表题为 Table 12.4 Arithmetic Average Annual Returns and Standard Deviation by Asset Class, 1981–2020，数据出处为 Aswath Damodaran Online；同表另有 Baa 级债券 10.34%／7.67%、十年期国债 8.21%／9.92%、美国国库券 3.94%／3.39% 与通胀 2.93%／1.76%。这些都是名义、算术平均口径，表本身不作实际化调整，所以本文的比值也只是按该表两列相除的自算。）[3]

失败条件

  • 用毛收益与别人的净收益比较；
  • 用名义收益代替实际收益，忽略通胀；
  • 只比较预期值，不看下跌情景和最大回撤；
  • 漏掉多层费用、税费或买卖价差；
  • 把历史高收益当成未来保证；
  • 期限错配，用短期资金承担长期波动；
  • 用杠杆或集中持仓弥补差距，放大无法承受的损失。

验证与复现

  1. 用精确公式复算每个情景，并记录近似公式的误差。
  2. 把费用改为按期末资产收取，检查结果变化。
  3. 至少用两个通胀率和三个收益情景做敏感性分析。
  4. 核对费用、税率和数据来源，让他人按同一口径复算。
  5. 记录假设和复核日期。

知识点精读

持有期与复合收益

定义：持有期是投资从买入到卖出的时间，复合收益是把各期收益连乘得到的年化增长。

机制：复合收益受波动拖累：算术平均高于几何平均，亏损后需要更大涨幅才能回本。

例子：例如两年收益 +50% 和 −50%，终值为 0.75，年化约 −13.4%，不是 0%。

边界：复合收益不是简单平均；现金流时点、费用和税会改变，短样本年化也会夸大或掩盖风险。

实际购买力

定义：实际购买力是扣除通胀后的收益，决定投资能否维持消费能力。

机制：实际收益近似名义收益减通胀；税收按名义收益征收会进一步降低，生活成本篮子也可能高于 CPI。

例子：例如名义收益 6%、通胀 4%，实际约 2%；若收益被征税，实际更低。

边界：实际购买力不是单一数字；不同家庭消费篮子、地区和医疗成本差异很大，CPI 也可能低估体感通胀。

费用税费

定义：费用是管理、托管、交易和销售成本，税费是利息、股息、资本利得和交易环节的税负。

机制：费用按资产比例持续侵蚀复利，税费取决于账户、持有期和实现方式；高换手会提高两者。

例子：例如年费 1% 在 30 年可能吃掉约四分之一终值，频繁交易还增加点差和税。

边界：费用不是越低越好；低成本可能牺牲服务、流动性和风控，税务优化也可能锁住资产或引入复杂结构。

汇率和基准选择

定义：汇率改变外币资产的折算回报，基准是评价组合表现的参照，应匹配投资范围和风险。

机制：未对冲外币收益等于本币资产收益加汇率变化；基准可选择市场、同业或负债，但必须一致且可投资。

例子：例如美元资产涨 8%、人民币升值 3%，本币回报约 5%；若基准是人民币债券，比较需说明币种差异。

边界：汇率不是噪音；对冲成本、利率差和相关性会改变风险，基准也可能被挑选成容易跑赢的“低标尺”。

数据与制度核对：名义收益

把“名义收益”放进真实数据之前，先核对四件事。第一是统计单位：来源报的是水平值、增长率、指数还是占比，分母是总产值、人口、劳动力还是金融资产；同一句话换掉分母就会得到不同结论。第二是时间口径：名义值与实际值、季调与非季调、财年与日历年不能直接拼接，涉及“实际收益”时尤其要写明基期和折算方法。

第三是制度边界。投资风险在来源国的法律、监管和会计规则下成立，换到另一套制度里，定义可能不覆盖同一批主体；跨境比较要先检查样本是否被同一规则约束。第四是反向核对：用另一个独立来源重算关键比例，至少让数量级、方向和单位对得上，再讨论因果。

边界条件与迁移练习：名义收益

学习“名义收益”最容易停在定义。真正要练的是把它和“实际收益”分开：前者回答哪个变量在动，后者回答这个变量通过什么渠道影响结果。两者经常同时出现，但一个描述状态，一个描述传导；把传导写成状态，就会把相关性误当因果。与“投资风险”的区别则在于层次：前者可以在单个主体上观察，后者要求一组共同规则约束同一批主体。三层混在一起，文章就会看起来什么都说了，实际什么都不能检验。

迁移练习的做法是换三个维度各问一次。换主体：从企业换到家庭，从银行换到基金，名义收益的分子分母是否仍然成立？换时间：从季度换到年度，从正常期换到危机期，参数是否稳定？换制度：从一套监管换到另一套，实际收益的激励是否方向相反？三次换完，仍能复述同一条机制，才算掌握；一换就崩，说明原来记住的是案例，不是概念。

最后做一次自测：用 100 字解释“名义收益”，必须包含一个单位、一个时间口径和一个反例；再用 100 字说明“实际收益”在什么条件下会失效。两段都写不出，就回到模块母文和同模块的另一篇主文，先把定义与口径对齐。模块深度不是字数，而是能否在换主体、换时间、换制度后仍给出可复核的判断。

复核题：名义收益

  1. 用一句话说明“名义收益”的分子、分母和单位，再说明它与“实际收益”不是同一个指标。
  2. 给出一个“投资风险”改变后结论翻转的例子，标明改变了哪条规则。
  3. 找一组跨期数据，说明季调、基期或修订如何改变方向。
  4. 设计一个换主体后的检验：从企业换到家庭，或从银行换到基金，哪些参数必须重估？
  5. 写一条可证伪判断：如果哪一个可观察信号出现，就应放弃本文结论？

五题不要求长答，但每题必须留下数字、日期或来源位置。答不出来，说明模块还停留在名词层；能答出来，才具备把概念迁移到新数据上的最低条件。

复核题

把「持有期与复合收益」「实际购买力」「费用税费」分别交给两个不熟悉该主题的人，请他们各自写出一个可观察指标和一个反例。若两人的指标指向不同对象，说明定义还没有落到可操作层面；若两人都写不出反例，说明边界还没有被真正理解。复核不是投票，而是看结论能否被独立重建。

练习

  1. 近似与精确。 某产品名义收益 8.0%，通胀 3.0%，费用 1.5 个百分点。净名义收益、近似实际收益和精确实际收益各是多少？
  2. 取舍判断。 方案 A 的基准实际收益为 3.41%，最差一年 -13.17%；方案 B 实际收益 0.68% 且波动很小。哪个更好？
  3. 费用含义。 为什么 1.0 个百分点的费用不能简单理解为“收益的 1%”？
参考答案
  1. 净名义收益 6.5%；近似实际收益 3.5%；精确为 1.065 / 1.03 - 1 = 3.40%。
  2. 没有唯一答案，取决于期限、流动性、风险承受能力和目标。A 的基准更高但下行更大，B 更稳但购买力增长有限。
  3. 费用按资产收取，占净收益的比例取决于毛收益。毛收益 2% 时，1 个百分点费用等于毛收益的一半；长期还会复利侵蚀终值。
  1. 用 100 字说明“INV-002”里的核心指标，必须写出分母和单位。
  2. 把“名义收益”与“实际收益”各写成一个可观察变量，并指出二者的时间差。
  3. 给“投资风险”找一个规则变化，说明它如何改变样本覆盖。
  4. 用本文的方法做一次反事实：只改变一个变量，其他条件保持不变。
  5. 如果换一个独立来源，哪一个数量级最可能变化？为什么？
  6. 写一条可证伪判断，包含观察信号、等待时间和复核指标。

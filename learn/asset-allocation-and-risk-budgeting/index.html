资产配置与风险预算

用两资产假设例子说明资本权重与风险贡献的差别，给出波动率、边际风险贡献和风险预算的计算步骤，并说明杠杆、相关性与估计误差的边界。

问题与输出

资产配置决定资本在股票、债券、现金等之间的比例；风险预算决定总风险如何分配到各资产。输出是目标权重、风险贡献、约束和监控规则，而不是收益最高的组合；它回答“谁在占用风险”，而不是“谁看起来权重最大”。

相关性之所以是必需输入，是因为 OpenStax 指出分散化只能降低公司特有风险、不消除系统风险，组合波动率也不是各资产波动率的简单平均，而由波动率与相关性共同决定，相关性越低分散效果越强[2]。

输入与数据要求

需要各资产波动率、相关系数与协方差矩阵、投资期限、流动性、杠杆和集中度限制；预期收益可选，但风险预算不以它为核心。估计要写明频率、窗口、币种和缺失处理，缺失值不得用前向填充掩盖。示例为假设的股票与债券：波动率 16% 与 6%，相关系数 0.20，初始权重 60/40。

把组合分散到股票、债券与现金等类别、按投资期限与风险承受能力确定配置，是 SEC 投资者指南对资产配置的定义；该指南同时提醒，再平衡把组合带回原配置时必须计入交易费用与税务后果[1]。

假设

二阶矩在样本内稳定；无交易成本；可按规则再平衡；只做多时不允许杠杆，使用杠杆需另行说明；风险用波动率度量。以下数字均为教学假设。

步骤

  1. 组合方差：σ² = 0.6²×0.16² + 0.4²×0.06² + 2×0.6×0.4×0.20×0.16×0.06 = 0.010714，σ = 10.35%。
  2. 边际风险贡献：MRC_i = (Σw)_i/σ。股票 0.1558，债券 0.0250。
  3. 风险贡献：RC_i = w_i×MRC_i。股票 9.35 个百分点，债券 1.00 个百分点，合计 10.35。
  4. 风险占比：股票 90.3%，债券 9.7%。60% 的资本承担约 90% 的风险。
  5. 若目标风险预算为 70/30，仅做多解约为股票 38.5%、债券 61.5%，总波动降至 7.78%。
  6. 要把总波动恢复到 10.35%，需约 1.33 倍杠杆，权重变为 51.1%/81.9%，合计 133.0%。
  7. 记录约束、再平衡阈值和风险贡献的监控口径。

“风险预算”的正式定义取自 arXiv 论文：它是预先设定每种资产对组合总风险贡献数量的组合策略，并用收益模拟来估计风险预算组合[3]。

结果解读

60/40 是资本比例，不是风险比例。低波动、低相关资产要获得更大资本权重，才能贡献同样的风险；纯风险预算不以预期收益为输入，因此不能保证收益或跑赢 60/40。协方差随环境和样本变化，风险贡献只是估计值；杠杆方案还会引入融资成本和追加保证金风险。风险预算的比例本身是治理选择，应写明分配理由、批准人和复核时间。

失败条件

  • 用历史协方差直接外推未来；
  • 压力期相关性往往会上升，分散效果可能明显减弱。这是本文的条件性提醒：所引三条来源（SEC、OpenStax 15.2 与 arXiv 摘要）都没有给出该实证结论，本文也不据此断言相关性一定趋近 1；
  • 波动率估计窗口过短或混用频率；
  • 忽略尾部、非正态和流动性；
  • 把风险预算当成收益预测；
  • 约束不允许理论权重；
  • 预算比例与投资目标或负债期限脱节；
  • 杠杆放大亏损和强平风险。

验证

使用滚动窗口和不同频率；在压力情景下重算风险贡献；与等权、60/40 和目标日期基金比较；检查样本外风险占比；报告估计误差、换手和约束影响，并检查结论是否依赖波动率这一风险度量。

复现

σ = √(wᵀΣw)；MRC_i = (Σw)_i/σ；RC_i = w_i×MRC_i；ΣRC_i = σ。示例：0.0935 + 0.0100 = 0.1035。

延伸判读

资产配置不是把资金平均分给几类资产，而是按风险贡献分配。股票波动高、债券波动低，等金额配置往往让股票贡献绝大部分风险；按风险预算配置，则低波动资产需要更大权重才能贡献相同风险。协方差决定分散效果：相关性上升时，组合风险不会按权重线性相加。杠杆可以放大收益，也放大相关性和流动性风险；再平衡规则要把漂移、成本和税收一起考虑。 上述制度与定义可对照公开资料 [4]；例子中的数字均为教学假设。

工作纸：把判断拆成可复核的四栏

本文的主题是“INV-018”。读完之后，不要先记结论，先做一张四栏工作纸：第一栏写“资产配置”的定义、分子、分母和单位；第二栏写“风险预算”的传导渠道；第三栏写“风险贡献”的制度边界；第四栏写结论的反证信号。四栏都填满，才允许把结论带进下一步；任何一栏空白，结论就只能当作假设。

第一栏最容易偷懒。把指标写成一句“越高越好”，等于没有定义。至少要回答：它衡量的是存量还是流量，分母是产出、人口、资产还是交易量，价格是名义还是实际，时间点是期末还是期间平均。换掉其中任何一个，排序和结论都可能改变。若来源只给了一个数字而没有给出分母，先回到来源脚注，不要用相邻文章的分母替代。

第二栏要把“风险预算”写成一条可观察的链：哪一个变量先动，经过什么中介，最后改变哪个结果。链上每一环都要有时间和单位，不能把“长期”与“季度”混写。链越长，越要标出哪一环是作者推演、哪一环有来源支持；推演可以用于教学，但不能冒充事实。

第三栏处理制度。风险贡献不是背景段落，而是样本定义：哪些主体被覆盖，哪些被豁免，规则从哪一天生效，跨境比较是否由同一套规则约束。制度不同，同样的数字会对应不同的激励；把制度差异写成行为差异，是跨市场比较里最常见的错误。若无法确认规则一致，就把比较降级为“两个独立情景”，不要给出排序。

第四栏写反证。用一句可证伪的话收尾：“如果观察到 A，在 B 时间内出现 C，则原判断成立；否则放弃。”A 必须是可观察的变量，B 必须是可以等待的时间，C 必须是可以复核的结果。三项写不清，说明结论还不可检验。最后把工作纸、来源链接和复核日期放在同一页；下一次复盘时，先看当时的四栏，而不是只看事后结果。

记录模板

把四栏压缩成一页：左栏写口径与单位，中栏写机制与制度，右栏写反证与复核日期。数据更新时只改数字，不改结论文字；若结论文字必须改，说明口径或制度变了，回到来源重做检查。记录里保留一栏反方意见，下一次复盘先问证据是否推翻了反方，再问仓位是否赚钱。

边界算例：相关性上升时，风险预算会怎样失效

用文中假设：股票波动率 16%、债券 6%、资本权重 60/40。相关系数 0.20 时，组合方差为 0.010714，总波动 10.35%；股票风险贡献 9.35 个百分点、债券 1.00 个百分点，风险占比约 90.3%/9.7%。

把相关系数改为 0.80，资本权重仍是 60/40。组合方差变为 0.013478，总波动 11.61%；股票风险贡献约 9.52 个百分点、债券 2.08 个百分点，风险占比约 82%/18%。资本权重没有变，风险占比却从 90/10 移向 82/18；这说明“60/40”是一个资本配方，不是风险配方。

相关系数 总波动 股票风险占比 债券风险占比
0.20 10.35% 90.3% 9.7%
0.80 11.61% 82% 18%

如果按 70/30 风险预算做仅做多配置，相关性 0.20 时约需股票 38.5%、债券 61.5%；相关性升到 0.80 后，同样的风险预算需要重新求解，不能沿用原权重。更关键的是，协方差是用历史窗口估的：危机期相关性上升，平静期下降；用平静期估计去加杠杆，会在压力期低估风险。

边界条件是：相关性不是常数，风险贡献不是资本权重，杠杆不能替代分散化。若相关性估计在滚动窗口中大幅跳动，先把风险预算降级为区间，并写清再平衡规则；不要用一个点估计宣称“风险已分配完毕”。

练习

  1. 计算。 60/40 组合中债券的风险占比是多少？
  2. 推理。 为什么 70/30 风险预算下股票权重低于 50%？
  3. 条件。 相关系数升到 0.80 时，总波动率和债券风险占比会怎样变化？
参考答案
  1. 约 9.7%。
  2. 债券波动低，要贡献 30% 风险需要更高资本权重；股票波动高，较少资本即可贡献大部分风险。
  3. 总波动率从 10.35% 升至 11.61%，债券风险占比从 9.7% 升至约 17.9%（股票降至约 82.1%）。
